# 0.8.0 — coverage diagnostics, version families and readable objects

This release changes the discovery/content workflow, not the frozen PDF success definition or Zotero write permissions.

- PubMed journal/book/chapter parsing preserves mixed source order and type-specific metadata, with returned/parsed/skipped/missing-ID diagnostics. Abstract HTML parsing preserves numerical comparison signs rather than dropping text between `<` and `>`.
- Optional `coverage-plan` produces auditable precision/native-broad strategies within a stated per-source result-slot budget. It does not silently change an original plan or guarantee recall. Splitting an existing cap can lose original hits: preserve the original search and use an explicitly larger supplementary budget when broad-route discovery is useful. Compare same-query version changes separately from changed-query strategy experiments.
- `work-families.json` retains all candidates and identifiers. Confirmed-provider relationships and conservative high-confidence metadata groups are distinct; comments, corrections, translations and conflicting bridges do not silently merge. A display representative does not replace version DOI/PDF identity or certify an independent cohort.
- HTML scientific body, abstract, navigation and backmatter have explicit roles. Table captions/footnotes bind to cells; empty/title-only tables remain incomplete. Declared external tables require matching parent and table identities.
- Authorized supplements can expose PDF text, DOCX paragraphs/tables/notes, XLSX cells/formulas-as-text and UTF-8 delimited/plain text to ordered reading packs. Identical file bytes are derived once within each article even when several URLs or figure/supplement declarations refer to them; all declarations remain traceable. Linked HTML table targets stay distinct. Unsupported files/images and unverified layout semantics remain gaps. Office files are parsed as bounded data without executing macros/scripts/formulas.
- Every derived reading element binds both its object bytes and the declaring article source. Preparation, receipts, continuation and reuse verify these sources; unread damaged assets may only be recovered through explicit assets-resume into a new artifact. Extraction is not host reading or understanding.

Compatibility: existing manifests and schema-v1/v2 reading packs remain verifiable. New reading packs retain schema v3 with optional object locators; article parser is article-document/4. No new third-party dependency, paid source, browser-cookie automation, Zotero write or Git publication is introduced.

Known limits: supplementary inventory is not exhaustive; image-only content needs visual reading/OCR; Word merged-row/layout semantics and spreadsheet formatting/date/chart interpretation are not certified. Coverage is bounded and source-dependent. Metadata grouping is a conservative local heuristic, not an externally validated identity classifier. Real benchmark outcomes must be reported from captured sources and explicit denominators, never inferred from regression-test counts.
