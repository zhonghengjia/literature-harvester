# Source and access policy

Read before live discovery or download work. Free official/OA routes are the default; this policy does not authorize automated institutional sessions.

## Permitted routes

- PubMed E-utilities, Crossref, Europe PMC, OpenAlex, Semantic Scholar and arXiv for bibliographic discovery. PubMed and Europe PMC are preferred for biomedical questions. Respect provider page bounds, pacing, partial-result errors and retry deadlines.
- OpenAlex OA locations (all declared qualifying locations), Unpaywall DOI locations, Semantic Scholar openAccessPdf and CORE repository records for legal free-copy discovery. CORE requires its configured API key in this adapter. Crossref links alone are not proof of OA.
- Exact-title preprint matches require compatible author/year evidence and explicit version-relation provenance. Similar/changed titles remain review candidates, not automatic file bindings. Multiple verified preprint DOIs are retained without replacing the journal DOI. bioRxiv/medRxiv versions resolve through official metadata; a challenge page is a manual fallback, not a bypass target.
- Eligible publisher/repository landing pages can be read for declared citation_pdf_url, eprints.document_url, PDF alternate links and explicitly typed PDF download anchors. Article HTML may supply body content after independent identity/body checks. Never guess publisher paths.
- Source-authorized native article pages may declare linked table pages and supplementary objects. Resolve exactly those declarations; same-page anchors are inventory, not independent downloads. Parent/table identity is required for linked-table HTML. Supplementary PDF/Office/text is associated with its declaring article and has separate raw-byte provenance; it is not another identity-verified paper. Do not crawl arbitrary links, execute Office content or infer that every attachment is complete. Unknown permissions remain unavailable; author-manuscript TDM does not authorize media retrieval.
- PubMed/Europe PMC/OpenAlex PMCID records register an official PMC Cloud resolver. Matching identity, license/access eligibility, declared object and official bucket path are required. Retraction is separate: a permitted retracted article remains readable with an explicit warning and cannot be treated as active evidence. Unknown retraction status is also labeled. A non-OA author manuscript with explicit TDM eligibility is text-only: retrieve its declared JATS, not arbitrary PDF/media objects.
- Official Europe PMC JATS may be used only when article OA eligibility is established. A bare PMCID alone is not that eligibility. The generated prose reader is not a lossless PDF substitute.

Use the current pmc-oa-opendata Cloud metadata contract, not retired FTP/OA Web Service routes or bulk HTML scraping. PMC version number is deposit-processing order, not proof of the published version. Preserve per-version warnings rather than hiding alternate-version failures.

## Ordering and fallback

PDF order is centralized in downloader.sorted_candidates: direct PDFs/resolvers, landing resolution, then the legacy JATS prose fallback. Content independently tries eligible JATS, verified local PDF, eligible article HTML and online PDF, without changing the source manifest's PDF counters. PMC prefers non-manuscript deposits before manuscripts, then newer processing versions; this is an explicit retrieval preference, not a claim of version-of-record identity. Keep URL, license, actual version, retraction and resolver evidence.

A failed direct candidate does not suppress later enrichment. Both PDF retrieval and independent content consult the enabled free-copy adapters for that failed record and try newly declared alternatives. Content does this once after existing native/local/remote routes fail; it never enables metered delivery, and local-only skips it. Resume restores host deadlines from both the frozen manifest and prior content index, retaining the later deadline. Unknown/incorrect article identity requires review; it does not count as successful retrieval. A missing route is not proof of a paywall. Provide original DOI/record pages, institutional library or interlibrary-loan options, repository searches and an author-request template.

## Budget and deferred adapters

OpenAlex content availability and article license are separate facts. Hosted PDF delivery is disabled by default. `free_only=true` remains non-spending because no server-enforced zero-charge guard has been verified; a daily allowance is not such a guard. The optional metered PDF route requires `enabled=true`, `free_only=false`, `allow_paid=true`, a positive max_files, a positive max_cost_usd and the API key. Obtain separate spending approval before enabling it. Each run reserves requests before I/O, saves a key-free metered-requests.json, and disables automatic retries for these files. The cost budget is a local estimate based on the dated official price in metered.py, not an account-wide or server-enforced billing guarantee. Concurrent processes and price changes are not covered. Candidates never store API keys. Hosted TEI parsing is not implemented.

OpenAIRE Graph v3 and DOAJ are enabled supplemental routes. Each verifies returned article identity; OpenAIRE checks each instance's OPEN status rather than collecting arbitrary nested URLs. CORE supports DOI or exact title/author/year matches and bounded pagination, but still needs its API key. Missing keys or failed adapters are reported. Explicit one-hop citation expansion is supported with frozen seed IDs and a new child run (research-reading.md); unrestricted recursive snowballing, additional regional repositories, publisher-paid TDM and automated institutional SSO are not implemented.

## Network and browser boundaries

General scholarly HTTP(S) requests use system/environment proxies. `is_web_url` checks syntax only: no DNS pre-resolution, public/private/loopback classification, domain allowlist or VPN switch. Source-declared anonymous HTTP reads keep their scheme; the program never fabricates an HTTPS upgrade or falls back to HTTP after a TLS failure. Credentials and writes require HTTPS, certificate/hostname checks remain on, and cross-origin redirects strip secret headers. Official PMC objects and credential-bearing APIs retain their specific HTTPS contracts. Optional transport.ca_file augments trusted certificates. This transport is not an internal-network isolation boundary. Offline browser evidence uses the same syntax-only policy; Zotero retains its distinct loopback boundary.

Identify the client with a stable user agent and contact address where required. Retry only bounded transient/idempotent operations. Preserve full Retry-After deadlines for the affected host, including across records and resumed runs; do not shorten them. Another independently eligible host may still be attempted; see manifest-schema.md for legacy unattributed deadlines. arXiv requests are serialized/paced within one process, including response reads; other processes/tools must coordinate usage.

Never use shadow libraries, leaked credentials, session theft, CAPTCHA bypass, access-control circumvention or redistribution. Do not guess paths or treat HTTP 200/PDF syntax as permission or article identity.

An explicit user-downloaded file may enter the manual browser handoff only with original-provider evidence and, for institutional access, confirmed entitlement. The handoff does not invoke EasyPubMedicine, read cookies, alter extension settings or attest that a plugin used a permitted source. See browser-handoff.md. Do not expose Zotero beyond loopback; library mutation requires its separately reviewed plan and explicit confirmation.
